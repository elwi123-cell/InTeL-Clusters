WHAT IS INCLUDED
- Responsive home page matching the approved InTeL homepage visual identity.
- Shared logo, navy/teal styling, typography, responsive navigation and footer.
- 14 core information/business pages.
- Four dedicated foundational pillar pages.
- 26 individual A–Z domain pages using the exact domain names and summaries from Business Profile v2.0.

- Detailed business, technology, architecture, services, roadmap, governance and performance content.

HOW TO RUN ON WINDOWS 11
1. Download and extract this ZIP file.
2. Open the extracted InTeL_Clusters_Full_Website_Kit_v3.0 folder.
3. Double-click index.html.
4. Use the top navigation menus to open all pages.
5. Internet access is needed for Google Fonts; the site otherwise runs locally.

IMPORTANT SETUP BEFORE PUBLICATION
- Update the placeholder mailto address in script.js to a verified InTeL business email.
- Add verified registered business details, jurisdiction, leadership, address, telephone, partnerships, certifications and achievements.
- The contact form uses the visitor's default email application; it is not connected to a server and does not store or transmit data to a backend.
- This is a static multi-page website package. Hosting, domain registration, database, authentication, CMS, analytics and server-side form processing are not included.
- Quantum advantage and advanced AI capabilities are described as research pathways and must be independently validated.
